## 🎯 项目概览

**Ripple** 是一个 AI-native KOC 内容增长平台，专为腾讯PCG校园AI产品创意大赛设计。核心价值是帮助大学生KOC（关键意见消费者）通过AI技术实现高效涨粉和内容增长。

### 核心特性
- 🔍 **9层搜索矩阵**：整合多平台数据源，实时获取行业动态
- 🧠 **知识图谱可视化**：2D炬图风格，150-300节点的丰富关系网络  
- 📊 **AI智能分析**：基于LLM的深度内容策略分析
- 🎯 **微信生态整合**：深度结合腾讯PCG业务（公众号、视频号、搜一搜）
- 📈 **实时数据流**：SSE流式响应，AI思考过程透明化

## 📈 项目发展历程

### Phase 1: 基础架构 (4月)
- 建立前后端技术栈（React 19 + FastAPI）
- 集成多个搜索引擎和LLM服务
- 实现基础的内容分析流程

### Phase 2: 功能完善 (4月下旬-5月上旬) 
- 30个TODO任务的系统性迭代
- UI/UX全面重构（Perplexity风格）
- AI体验增强（内联引用、Follow-up问题）
- 7个竞赛对齐Demo案例开发

### Phase 3: 知识图谱升级 (5月6日)
- **关键转折点**：用户反馈图谱"很垃圾"
- 从3D星云风格→2D炬图风格
- 节点数量从70个→300个
- 包体积减少390KB，性能提升2倍

## 💻 技术架构

### 前端技术栈
```typescript
// 核心框架
React 19 + TypeScript + Vite

// UI库
Tailwind CSS 4 + Framer Motion + Shadcn/ui

// 可视化
react-force-graph-2d (替代Three.js)

// 状态管理  
React Hooks + Context API

// 通信
Server-Sent Events (SSE)
```

### 后端技术栈
```python
# Web框架
FastAPI + Uvicorn + asyncio

# AI服务
MiniMax + 腾讯Hunyuan + DeepSeek + OpenAI

# 数据处理
asyncio + aiohttp + BeautifulSoup

# 搜索引擎
Google + Bing + 腾讯搜索 + 垂直平台API

# 数据库
SQLite (开发) + Redis (缓存)
```

### 架构亮点
1. **流式响应**：AI思考过程实时可见，用户体验佳
2. **模块化设计**：搜索/分析/图谱各模块独立，易扩展
3. **多LLM支持**：自动fallback和负载均衡
4. **缓存优化**：Demo案例预缓存，评委体验0延迟

## 🔧 部署和运行

### 本地开发环境
```bash
# 前端服务
cd ripple3/web && npm run dev
# http://localhost:5173

# 后端服务  
cd ripple3 && python -m uvicorn api.routes:app --reload
# http://localhost:8000
```

### 环境要求
- Node.js 18+ (前端构建)
- Python 3.10+ (后端服务)
- 各LLM服务API密钥（MiniMax必需，其他可选）

### 配置文件
- `ripple3/.env`: 后端环境变量（API密钥）
- `ripple3/web/.env`: 前端环境变量（API端点）
