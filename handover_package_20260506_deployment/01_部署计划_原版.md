# Ripple 全站部署到阿里云（120.55.247.6）

## 服务器信息
- IP: `120.55.247.6`，用户名: `root`，密码: `Ripple@2026!`
- 配置: Ubuntu 22.04，4核 8GiB（全新服务器，创建于 2026-04-24）

## 部署架构

```
http://120.55.247.6/        → Pitch 介绍网页（ripple-site，端口 80）
http://120.55.247.6:8080/   → Ripple Demo 应用（ripple3/web 构建产物，端口 8080）
```

介绍网页内"立即体验 Demo"和"打开 Demo →"两个按钮均指向 `:8080`。

Demo 应用无需后端/API Keys，点击 6 个预制案例零延迟展示完整产品流。

## 执行步骤

### Step 1：检查服务器现状
- SSH 连入，检查 `/root`、`/var/www`、`/home` 是否有旧文件
- `systemctl list-units --type=service --state=running` 查旧服务
- `nginx -v` 检查 nginx 是否已安装

### Step 2：清理旧内容（如有）
- 停止并禁用旧服务
- 删除 `/var/www/` 下旧文件
- 删除 `/root/` 下旧仓库目录

### Step 3：修改介绍网页中的按钮链接
在 [`website/ripple-site/index.html`](website/ripple-site/index.html) 中：
- 第 58 行：`href="http://localhost:5173"` → `href="http://120.55.247.6:8080"`
- 第 462 行：`ripple · localhost:5173` → `ripple · 120.55.247.6:8080`
- 第 474 行：`href="http://localhost:5173"` → `href="http://120.55.247.6:8080"`
- 第 479 行：说明文字更新为服务器地址

### Step 4：本地构建 Ripple Demo
```bash
cd ripple3/web
npm install
npm run build   # 输出到 ripple3/web/dist/
```
（无需修改 vite.config.ts，Demo 运行在根路径 `/`）

### Step 5：上传文件到服务器
```bash
# Pitch 介绍网页（3 个静态文件）
scp -r website/ripple-site/* root@120.55.247.6:/var/www/pitch/

# Ripple Demo 构建产物
scp -r ripple3/web/dist/* root@120.55.247.6:/var/www/ripple/
```

### Step 6：安装 nginx 并配置双站点
```nginx
# /etc/nginx/sites-available/ripple

# 介绍网页 - 端口 80
server {
    listen 80;
    server_name 120.55.247.6;
    root /var/www/pitch;
    index index.html;
    location / {
        try_files $uri $uri/ /index.html;
    }
}

# Demo 应用 - 端口 8080
server {
    listen 8080;
    server_name 120.55.247.6;
    root /var/www/ripple;
    index index.html;
    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

### Step 7：验证
- `http://120.55.247.6/` → Pitch 介绍网页加载正常
- 点击"立即体验 Demo"→ 跳转到 `http://120.55.247.6:8080/`
- Demo 页面 6 个案例点击后零延迟展示

## 关键文件
- 介绍网页: [`website/ripple-site/index.html`](website/ripple-site/index.html)（需修改 2 处按钮链接）
- Demo 前端: [`ripple3/web/`](ripple3/web/)（需 npm build）
- Vite 配置: [`ripple3/web/vite.config.ts`](ripple3/web/vite.config.ts)（无需修改）
