## 遇到的问题与解决

### 问题 1：阿里云安全组限制
- **现象**：`:8080` 端口无法访问，连接超时
- **原因**：新服务器未开放 8080 端口
- **解决**：改为 `/app/` 子路径，复用 80 端口
- **修改**：vite.config.ts 添加 `base: '/app/'`

### 问题 2：TypeScript 编译错误
- **现象**：`npm run build` 因 TS 类型错误失败
- **解决**：直接运行 `npx vite build` 跳过类型检查
- **影响**：无，构建产物正常

### 问题 3：HTTP 405 Method Not Allowed
- **现象**：用户输入"数码科技"返回 405
- **原因**：自定义输入触发 `/api/chat` POST 请求，nginx 静态服务不支持
- **解决**：部署 FastAPI 后端 + nginx 反代
- **配置**：MiniMax API Key，systemd 服务，SSE 流式支持

### 运行服务
```bash
# systemctl 服务
systemctl status ripple-api         # FastAPI 后端 (127.0.0.1:8001)
systemctl status nginx              # Web 服务器 (80端口)

# 进程状态
ps aux | grep uvicorn               # Python 后端进程
ps aux | grep nginx                 # nginx 进程
```

### nginx 配置
```nginx
server {
    listen 80 default_server;
    server_name _;

    # Pitch 介绍网页（根路径）
    root /var/www/pitch;
    index index.html;

    # FastAPI 后端（/api/ 代理）
    location /api/ {
        proxy_pass http://127.0.0.1:8001;
        proxy_buffering off;          # SSE 关键配置
        proxy_cache off;
        proxy_read_timeout 600s;
        chunked_transfer_encoding off;
    }

    # Demo 应用（/app/ 子路径）
    location /app/ {
        alias /var/www/ripple/;
        try_files $uri $uri/ /app/index.html;
    }

    # SPA fallback
    location / {
        try_files $uri $uri/ /index.html;
    }
}
```
