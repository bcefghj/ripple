### 3. `/etc/nginx/sites-available/ripple` - nginx 站点配置

```nginx
server {
    listen 80 default_server;
    server_name _;

    # Pitch 介绍网页（根路径）
    root /var/www/pitch;
    index index.html;

    # FastAPI 后端（/api/ 代理）
    location /api/ {
        proxy_pass http://127.0.0.1:8001;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 600s;
        proxy_http_version 1.1;
        proxy_set_header Connection '';
        chunked_transfer_encoding off;
    }

    # Ripple Demo 应用（/app/ 子路径）
    location /app/ {
        alias /var/www/ripple/;
        index index.html;
        try_files $uri $uri/ /app/index.html;
    }

    # Pitch 介绍网页（SPA fallback）
    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

## 🎯 配置要点说明

### nginx 配置关键点

1. **SSE 流式传输支持**
   ```nginx
   proxy_buffering off;           # 禁用缓冲
   proxy_cache off;               # 禁用缓存
   chunked_transfer_encoding off; # 流式传输
   ```

2. **SPA 路由支持**
   ```nginx
   try_files $uri $uri/ /app/index.html;  # Demo 应用
   try_files $uri $uri/ /index.html;      # Pitch 网页
   ```

3. **反代配置**
   ```nginx
   proxy_pass http://127.0.0.1:8001;  # 后端地址
   proxy_read_timeout 600s;           # 长连接支持
   ```

### Vite 配置关键点

1. **子路径部署**
   ```ts
   base: '/app/'  // 所有资源路径加前缀
   ```

2. **开发代理**
   ```ts
   proxy: {
     '/api': {
       target: 'http://localhost:8001'  # 开发时代理
     }
   }
   ```

### systemd 服务关键点

1. **自动重启**
   ```ini
   Restart=always
   RestartSec=5
   ```

2. **环境变量**
   ```ini
   EnvironmentFile=/opt/ripple/.env
   ```

3. **多进程**
   ```ini
   ExecStart=...uvicorn... --workers 2
   ```

## ⚠️ 注意事项

1. **API Key 安全**: `.env` 文件包含敏感信息，权限设为 600
2. **端口冲突**: 确保 8001 端口未被占用
3. **文件权限**: nginx 需要读取 `/var/www/` 下的文件
4. **服务依赖**: ripple-api 依赖网络，nginx 依赖 ripple-api
5. **备份重要**: 配置文件和 API Keys 需要定期备份

## 🔄 回滚方案

