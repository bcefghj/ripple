### 阶段 5：解决 405 问题 (19:03-19:09)

**用户测试发现**：
> 数码科技 分析  
> 复制为  
> HTTP 405 这是什么问题？ http://120.55.247.6/app/

**AI 诊断**：
- 6个预制 Demo 按钮 → 加载静态数据，无需后端 ✅
- 自定义输入"数码科技" → 触发 `/api/chat` POST 请求 → 405 ❌
- nginx 静态文件服务不支持 POST 方法

**解决方案：部署 FastAPI 后端**
- 打包后端代码 (`ripple3/` 除 `web/`)
- 服务器创建 Python venv 并安装依赖
- 配置 MiniMax API Key (从凭据文件获取)
- 创建 systemd 服务自动启动
- 更新 nginx 配置添加 `/api/` 反代

**最终架构**：
```nginx
server {
    listen 80;
    
    # Pitch 网页 (/)
    root /var/www/pitch;
    
    # Demo 应用 (/app/)
    location /app/ {
        alias /var/www/ripple/;
    }
    
    # FastAPI 后端 (/api/)
    location /api/ {
        proxy_pass http://127.0.0.1:8001;
        proxy_buffering off;  # SSE 支持
    }
}
```
