Problem

深度工作，正在被切碎。

办公工具擅长分配任务、催促进度，却从来没有保护过人的工作状态。打断不是技术问题，是一个被长期忽视的体验问题。

"大多数深度工作失败，不是因为不会做，而是因为工作流被消息和沟通切碎。" — 李洁盈 · 团队产品观
Solution

FlowGuard 做四件事。

不是简单的免打扰。是一个理解工作上下文、主动做决策、被打断后仍能帮你回到状态、并通过 MCP 对外赋能其他 Agent 的完整守护系统。

Smart Shield

6 维分类，看得懂、可解释、能回滚。

大多数 AI 黑箱让人不敢用。FlowGuard 给每个决策生成 6 维评分卡，用户能看、能问、能改正。

Security · Trust

8 道闸门 · OWASP LLM Top 10 全覆盖。

每条消息都会过 8 道闸门，任何一道发现风险都会 audit-log 一条 HIGH/WARN 事件，并被分级降级或直接拦截。所有决策可在 Dashboard 一键回滚。Promptfoo 红队 14/14 PASS。

企业敢用的前提：说清楚不越界。
