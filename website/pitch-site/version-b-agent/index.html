problem

Deep work is being shredded.

办公工具擅长分配任务、催促进度，却从来没有保护过人的工作状态。打断不是技术问题，是被长期忽视的体验问题。

大多数深度工作失败，不是因为不会做，而是因为工作流被消息和沟通切碎。 — 李洁盈 · 团队产品观
solution

FlowGuard ships 4 things.

不是简单的免打扰。是一个理解工作上下文、主动做决策、被打断后仍能帮你回到状态、并通过 MCP 对外赋能其他 Agent 的完整守护系统。

smart-shield

6-dim classification · explainable, rollbackable.

大多数 AI 黑箱让人不敢用。FlowGuard 给每个决策生成 6 维评分卡，用户能看、能问、能改正。规则兜底 + LLM 仅在边界仲裁，准确率 99%、LLM 调用率 < 12%。
