## 1. 为什么要做新网页

旧版 `version-a-editorial/`（上线在 http://118.178.242.26/version-a-editorial/）是 FlowGuard v3 时代的产物：

- 文案还是"FlowGuard"，不是"LarkMentor"
- 章节结构只有 6 段，覆盖不了新版 Mentor 4 Skill
- 动画太少：只有 scroll reveal + 一个 Live Demo 播放器
- Dashboard / MCP 都是旧样式
- 没有 PDF 下载入口

**目标**：做一个能让评委 5 分钟内完全看懂 LarkMentor 是什么、能做什么、背后怎么实现、代码是真的能跑的产品级页面。

## 2. 不用框架，为什么

| 方案 | 优点 | 缺点 |
|---|---|---|
| React / Vue | 组件化、生态好 | 需要构建环节；评委机器若无网 CDN 挂掉 |
| 纯 HTML + CSS + JS | 三文件直接 scp 上去 | 需要自己实现 DOM 操作 |

选择**纯原生**。评委 demo 是高压场景，不能依赖构建、不能依赖网络（Google Fonts 是可选的，失败就降级系统字体）。

写了一个极简的 `h()` 辅助函数，模拟 React `createElement`：

```js
const h = (tag, attrs={}, children=[]) => {
  const el = document.createElement(tag);
  Object.entries(attrs).forEach(([k,v]) => {
    if (k === 'class') el.className = v;
    else if (k === 'style' && typeof v === 'object') Object.assign(el.style, v);
    else if (k.startsWith('on') && typeof v === 'function') el.addEventListener(k.slice(2), v);
    else el.setAttribute(k, v);
  });
  (Array.isArray(children) ? children : [children]).forEach(c => {
    if (c == null) return;
    if (typeof c === 'string') el.appendChild(document.createTextNode(c));
    else el.appendChild(c);
  });
  return el;
};
```

这样可以写类 JSX 的嵌套结构，不用大量 `innerHTML` 拼字符串。

## 3. 颜色系统

| 变量 | 浅色值 | 深色值 | 用途 |
|---|---|---|---|
| `--accent` | `#3370FF` | `#6699FF` | 飞书品牌蓝，主行动色 |
| `--warn` | `#F59E0B` | `#FBBF24` | 琥珀黄，强调/P1 |
| `--ok` | `#10B981` | 同 | 绿色，P2/成功 |
| `--bad` | `#EF4444` | 同 | 红色，P0/错误 |
| `--bg` | `#fafaf9` | `#0a0a09` | 页面背景 |
| `--fg` | `#0a0a09` | `#f5f5f3` | 主文字 |
| `--line` | `#e7e7e4` | `#2a2a27` | 分割线/边框 |

双主题通过 `[data-theme="dark"]` 选择器切换，用 `localStorage.getItem('lm-theme')` 持久化，随系统偏好自动设置初始值：

```js
if (!saved && matchMedia('(prefers-color-scheme:dark)').matches)
  html.setAttribute('data-theme','dark');
```

## 5. 字体选择

- 正文：`Inter`（Google Fonts，西文设计感强）+ `PingFang SC` / `Microsoft YaHei` 回退（中文）
- 代码/数字/monospace：`JetBrains Mono`（代码片段、MCP 工具名、审计日志）

加载方式：`<link rel="preconnect">` 预热 + `<link href="...display=swap">`，字体加载慢时不阻塞渲染。

## 6. 响应式处理

核心用 CSS Grid `auto-fit` + `minmax`：

```css
.solution-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 20px;
}
```

hero、pains、memory 等需要左右对齐的布局用媒体查询单独处理：

```css
@media (min-width: 980px) {
  .hero-grid { grid-template-columns: 1.1fr 1.05fr; }
}
```

移动端下 IM 模拟器会叠在文字下方，不影响可读性。
