## 1. Dashboard 改造

### 1.1 改了什么

旧版 `dashboard_v3.html` 是 Tailwind CDN + 朴素表格，FlowGuard 文案。新版：

- 完全重写 HTML + CSS（与主页同一设计语言：`--accent:#3370FF`，`Inter` 字体，圆角 14px 卡片）
- 加入**4 个动画卡片**（入场动画 `opacity:0 → 1` + `translateY(14px) → 0`）
- 加入**demo 数据 fallback**：open_id 为空或 fetch 失败时展示内置数据，确保评委打开即有内容
- Wrapped 圆环图改为原生 SVG（不依赖图表库）
- 审计日志每行加 `animation-delay: i*40ms`，产生"日志流式涌入"效果

### 1.2 Demo fallback 实现

```js
const DEMO_WEEKLY = {
  stats: { msgs:482, p0:7, p1:23, focus_min:1245, mentor_drafts:19 },
  body_md: `📅 本周回顾 · ou_demo_user_0001\n\n...`
};

async function loadWeekly(openId) {
  // 如果 openId 为空，直接用 demo
  const d = openId ? await safeJson(`/api/v3/weekly?open_id=${encodeURIComponent(openId)}`) : null;
  renderWeekly(d || DEMO_WEEKLY);   // fetch 失败也用 demo
}
```

`safeJson()` 内部 try/catch，任何网络错误返回 null：

```js
async function safeJson(url) {
  try {
    const r = await fetch(url);
    if (!r.ok) return null;
    return await r.json();
  } catch(e) { return null; }
}
```

### 1.3 Wrapped 圆环图

原生 SVG `stroke-dasharray` 实现圆弧：

```html
<circle cx="18" cy="18" r="15.915" stroke-dasharray="0 100" id="donutFg"
        style="transition: stroke-dasharray 1.1s cubic-bezier(.2,.8,.3,1)"/>
```

加载数据后：

```js
const pct = d.focus_pct ?? 60;
donutFg.setAttribute('stroke-dasharray', `${pct} ${100-pct}`);
donutTxt.textContent = pct + '%';
```

由于有 CSS transition，圆弧会从 0 动画到目标弧度。`stroke-dasharray` 的计算方式：`r=15.915` 时周长 ≈ 100，所以 `pct` 直接就是百分比。

### 1.4 API 路径（不变）

Dashboard 复用旧有 FastAPI 后端，所有 API 路径原样保留：

| API | 说明 |
|---|---|
| `GET /api/v3/weekly?open_id=...` | 本周工作回顾 |

## 2. MCP Server 改造

### 2.1 旧版的问题

旧版 `server.py` 的 `_Handler` 只处理两个路径：

```python
def do_GET(self):
    if self.path == "/" or self.path.startswith("/list_tools") or self.path.startswith("/tools"):
        self._json(200, {"server": "FlowGuard", "tools": list_tools()})
    elif self.path == "/health":
        self._json(200, {"status": "ok"})
    else:
        self._json(404, {"error": "not_found"})
```

问题：
- 没有可视化页面（评委只能看 JSON）
- `server` 字段写的是 `"FlowGuard"`，不是 `"LarkMentor"`
- 没有 CORS 头（前端 fetch 可能跨域失败）
- 没有 `/mcp/tools.json` 别名
- 没有 OPTIONS preflight 处理

### 2.2 新增内容

**1. `_render_visual_html()` 函数**

自包含的 HTML 字符串，列出所有 MCP 工具卡片，点击可在线 call：

```python
def _render_visual_html() -> str:
    tools = list_tools()
    tools_json = json.dumps(tools, ensure_ascii=False)
    return (
        "<!doctype html>..."
        "<script>"
        "var TOOLS=" + tools_json + ";"
        "// 渲染 14 个工具卡片，点击 → POST /mcp/call"
        "</script>"
    )
```

工具列表通过 `json.dumps()` 注入 JS 变量，一次 HTTP 响应包含所有数据，不需要额外 AJAX 请求。

**2. 新增路由**

```python
def do_GET(self):
    # 可视化页面（根路径 / 也返回，方便 nginx /mcp 反代）
    if self.path in ("/", "/mcp", "/mcp/", "/visual"):
        self._html(200, _render_visual_html())
        return
    
    # JSON 工具列表（兼容旧路径 + 新别名）
    if (self.path.startswith("/list_tools")
        or self.path.startswith("/tools")
        or self.path.startswith("/mcp/tools")):
        self._json(200, {"server": "LarkMentor", "tools": list_tools()})
        return
```

**3. CORS 头**

```python
def _json(self, status, payload):
    body = to_json(payload).encode("utf-8")
    self.send_response(status)
    self.send_header("Content-Type", "application/json; charset=utf-8")
    self.send_header("Access-Control-Allow-Origin", "*")   # 新增
    ...

def do_OPTIONS(self):
    self.send_response(204)
    self.send_header("Access-Control-Allow-Origin", "*")
    self.send_header("Access-Control-Allow-Methods", "GET, POST, OPTIONS")
    self.send_header("Access-Control-Allow-Headers", "Content-Type")
    self.send_header("Content-Length", "0")
    self.end_headers()
```

### 2.3 nginx 路由（不需要改）

原有 nginx 配置：

```nginx
location /mcp/  { proxy_pass http://127.0.0.1:8767/; }
```

`/mcp/` 整段反代到 8767，新增的 `/mcp`（精确匹配）、`/mcp/tools.json`（子路径）全部自动暴露，**无需改 nginx**。

nginx 在反代时会 strip location 前缀：
- 公网 `GET /mcp` → 后端收到 `GET /`（精确匹配 `/`）
- 公网 `GET /mcp/tools` → 后端收到 `GET /tools`
- 公网 `GET /mcp/tools.json` → 后端收到 `GET /tools.json`
- 公网 `POST /mcp/call` → 后端收到 `POST /call`
